How to read this board. A protocol is listed when it records no token in the snapshot and is not a wrapped, staked or bridged product of a token that already trades. Its implied value is its TVL multiplied by the market value per TVL dollar of launched protocols in its category (a median, shrunk toward the global median), adjusted by two fitted terms: one for its 7-day TVL momentum, one for how long it has run with no token. Every term is fitted from the snapshot itself at build time — run the same program on a newer snapshot and the board re-fits and re-ranks on its own. Click any row for the full equation and its farm plan.
